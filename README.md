# fruit_project_codes
These codes are relevant to the project named "Biofilm from Alginate and Pomelo peels extract"

โดย fruit_analysis.xlsx คือผลจากการวัดค่าสี

และ fruit_weight.xlsx คือผลการสูญเสียน้ำหนักของผลไม้

หมายเหตุ** 

	A01-A02 คือฝรั่ง, A03-A04 คือแอปเปิล

	A05-A06 คือสาลี่, A07-A08 คือมะเขือเทศ

	เลขคี่ คือผลไม้ที่ไม่ได้เคลือบ เลขคู่คือผลไม้ที่เคลือบ
